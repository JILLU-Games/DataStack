# Page Sections Manifest

## Purpose
Modular feature sections used across the public landing page and `/vcon/*` administration views.

## Components
- `Hero.tsx`: Public overview hero section with architecture highlights and quick navigation links.
- `Features.tsx`: Core platform capability cards (WebSocket ingestion, partitioned CSV storage, SDK management).
- `SdkSection.tsx`: Interactive Python SDK code preview on the landing page.
- `LandingAbout.tsx`: Deployment and storage architecture summary section.
- `AdminLogin.tsx`: Administrator sign-in form with theme switcher and session persistence toggle.
- `AdminSetup.tsx`: Initial administrator account creation form.
- `ClientsView.tsx`: Client management workspace with search, status filters, and registration modal.
- `ClientsTable.tsx`: Client registry table with credential display, key rotation, access revocation, and deletion modals.
- `ExportWorkspace.tsx`: CSV and JSON dataset export builder with client/date filtering and recent partition downloads.
